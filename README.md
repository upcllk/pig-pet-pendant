# Pig Pet Pendant | 猪猪鼠标挂件

使用 Swift/AppKit、透明非激活面板实现的本地鼠标挂件。可在绳子挂件、猪猪气球、网兜小猪、竹子小猪、上吊猪和幽灵猪之间切换；保留正常系统指针，不安装后台服务，不访问网络，不申请辅助功能或屏幕录制权限。

Windows 后续开发见 [Windows 移植方案与接力指南](docs/WINDOWS_PORT_PLAN.md)。目前仅提交方案和架构图，尚无 Windows 工程或 EXE；现有 macOS 构建方式不变。

## 六种模式

- 绳子挂件：默认模式，使用原始捆绑小猪，单只向下悬挂，保留原绳索、重力和摆动效果，不修改原 PNG。
- 猪猪气球：使用从用户提供的“猪气球”参考图中提取的圆形猪气球，不再使用捆绑猪图片。去除背景，保留原图的猪脸与耳朵，在底部绘制细窄圆头的短收口和细小褶线，让绳子自然接入，不画尖三角或向两侧外翻的箭头状底边。
- 网兜小猪：使用用户提供的原动画，逐帧清理灰色杂边与左侧文字，并根据原蓝线两端的像素局部补齐白灰杂块和短小断点，保留猪脸与正常透明网眼，不重绘角色。绳端连接网兜顶部，整体向下悬挂；62 帧、每帧 40 毫秒，总长 2.48 秒循环。原文件虽然名为 GIF，实际为透明 WebP，应用内使用保留原画布与时序的无损透明 APNG。
- 竹子小猪：使用用户竹子参考图提取的原小猪，清除背景和游离竹节色点，保留原表情与轮廓。只画从鼠标连接点开始的一条连续竹子，带竹节、亮面和少量竹叶，不再拼接上方绳段和下方托钩。移动时平滑抬向横向，停住约 0.2 秒后开始顺时针弯垂，约两秒后停在根部偏横、末端向下的明显弧形，不会收成笔直竖线，小猪头朝上贴抱末端；再次移动会从当前姿态连续抬回偏横，不因上下快速反向或大幅移动闪帧、重置受力姿态。竹子摆角平滑跟随参考绳受力，曲线按近似弧长构造，最终近似四分之一圆弧。沿用弹性绳的受力与摆动参考，附加停留时间驱动的视觉弯曲，不是真实竹竿受压弯曲模拟，不改原图或保存参数。弯垂结束且受力状态稳定后才休眠，隐藏或系统睡眠时暂停。
  横向时小猪默认位于竹身中点；设置中的“小猪位置”滑杆可按竹根到竹梢的比例调节，数值会保存。弯垂从当前角度连续平滑转向，不会因停顿或细小鼠标抖动跳回横向，小猪再沿竹身逐渐向下滑向竹梢。
- 猪上吊：使用独立透明小猪素材，保留原画笔触；局部补齐头上的浅黄色光环，使轮廓闭合，不改动角色。由现有弹性绳从鼠标系绳点向下悬挂，跟随移动并摆动。
- 幽灵猪：使用从用户参考图提取的独立透明小猪素材，保留原画笔触及完整闭合的光环轮廓；不绘制绳子，在鼠标附近以平滑跟随方式移动，停止收敛后降低更新频率。设置中只显示小猪尺寸及水平、垂直偏移，不显示绳长、重量、弹性、衰减或重力；偏移单位为点，正水平向右、正垂直向上，范围各为 -300–300 点，默认位置约为鼠标右 44、上 32 点。
- 气球模式在一个应用进程中显示 1–8 只，默认数量两只，不靠多开应用实现。每只气球独立模拟，共用鼠标附近的系绳点，采用错落的尺寸、绳长和侧向气流。
- 移动鼠标时由弹性绳牵引气球，保留惯性、转向滞后和松弛；静止收敛后停止无意义更新，不持续播放预设浮动动画。
- 尚无气球间碰撞或屏幕边界约束；极短绳、大尺寸、多气球可能交叠，靠近屏幕顶部或使用长绳时可能越界。

## 构建和启动

当前仓库提供 macOS 客户端源码；Windows 版本仍处于移植规划阶段。构建后的 `.app` 可在 Finder 双击运行，或拖入“应用程序”。菜单栏小猪在应用运行期间常驻，关闭设置窗口不会退出挂件；菜单中的“退出猪猪挂件”才会彻底结束进程。

需要 macOS 12 或更新版本及 Xcode Command Line Tools。从仓库根目录构建：

```bash
./build.sh
open dist/PigPendant.app
```

运行核心与 GUI 冒烟检查：

```bash
./build.sh --test
```

GUI 检查需要已登录的桌面会话，会短暂显示测试挂件并自动退出；脚本会备份并恢复现有偏好。构建采用本机架构，显式设置 macOS 12 部署目标，进行 ad-hoc 签名及验证；这不等于 Developer ID 签名或公证，跨机器分发可能触发 Gatekeeper。构建产物位于被 Git 忽略的 `dist/`，不会提交到仓库。

## 菜单栏和设置

点击顶部菜单栏的旋转小猪图标，选择“设置…”打开原生设置窗口，在顶部切换六种挂件模式；菜单栏使用用户提供的小猪透明 GIF，以 28 点为基础图像、在 42 点画布内显示，整张图像绕中心以每圈约 1.2 秒的周期持续旋转，并在当前尺寸的 60%–140% 间随机平滑缩放。GIF 含 60 帧，按原始帧时长播放。也可直接通过菜单栏的“模式”子菜单切换。模式自动保存，气球数量仅在气球模式显示；其余模式隐藏整行并收紧窗口，不再置灰占位，也不清空已有数量。六种模式分别保存各自的尺寸和物理参数，切换不会覆盖其他模式的调参。幽灵模式只显示尺寸和鼠标偏移，隐藏无绳跟随无关的绳长、重量、弹性、衰减与重力；菜单栏也不显示无关的绳长快捷选项。升级时旧版共用参数会复制为各模式的初始值，保留已有调参。竹子模式将长度和弹性标签改为竹子，保存键不变；竹子视觉长度至少为小猪宽度的 1.5 倍，以容纳角色，不修改保存的长度值。保留尺寸、绳长快捷选项、显示/隐藏、重置和退出入口。再次打开已经运行的应用会显示设置窗口，不需要新开实例。

菜单栏小猪图标在 28 点画布内向右微移约 1 点。快捷菜单会随当前模式更新显示对象、尺寸/长度标签、重置姿态和状态说明；气球数量快捷选项仅在气球模式显示。

| 设置项 | 范围 | 默认值 |
| --- | --- | --- |
| 模式 | 绳子挂件 / 猪猪气球 / 网兜小猪 / 竹子小猪 / 猪上吊 / 幽灵猪 | 绳子挂件 |
| 气球数量 | 1–8 只，仅气球模式显示 | 2 只 |
| 绳子长度 | 20–1200 点，基准未受力长度 | 140 点 |
| 小猪尺寸 | 16–256 点，基准宽度 | 48 点 |
| 重量感 | 0–200，末端质量按指数映射 | 65 |
| 绳子弹性 | 0–200，越高越容易伸长 | 55 |
| 摆动衰减 | 0.2–8 /秒，越小摆动越久 | 约 0.91 /秒 |
| 高级：重力 / 浮力 | 100–10000 点/秒²，随模式显示 | 1350 点/秒² |
| 小猪位置 | 0–100%，竹根到竹梢，仅竹子模式显示 | 50%（竹身中点） |
| 幽灵猪水平 / 垂直偏移 | 各 -300–300 点，仅幽灵猪模式显示；正水平向右、正垂直向上 | 44 点 / 32 点 |

模式、数量和滑块调整即时生效，通过 UserDefaults 自动保存；“恢复默认”重置上述设置，恢复原绳子模式。六种模式各自保存尺寸及六项参数，重力/浮力沿用旧版 `Gravity` 的数值含义，仅气球模式向上，其余绳挂件模式向下；升级时将旧版共用参数复制为每种模式的初始值。竹子模式另有“小猪位置”滑杆，范围 0–100%，默认 50%（竹身中点），仅该模式显示；幽灵猪模式只显示尺寸和水平、垂直偏移，不显示与无绳跟随无关的物理参数。模式专属设置隐藏时会收起整行且不清除保存值。切换会重置姿态但不覆盖其他模式的参数，气球数量在非气球模式下保留但不生效。设置窗口和快捷菜单保持同步；“完成”或关闭窗口后，菜单栏及挂件继续运行。只有主动打开设置时才激活窗口，透明挂件仍不可获取焦点。没有新增后台服务或权限要求。

扩展范围不改变默认值或已有设置。长绳可能使小猪超出屏幕；低衰减会显著延长摆动。重量感和弹性不是百分比，超过 100 时继续增强，参考弹性绳额外伸长仍最多为绳长的 12%。竹子显示弧长固定为保存长度与小猪宽度 1.5 倍中的较大值；参考绳的受力只影响摆动，不再把参考绳松弛时缩短的端点距离当作竹长，也不驱动竹子伸缩。

要尝试长绳拖拽重物，可以从绳长 300 点、重量感 80、弹性 65 开始调节。该组合是试用建议，不是已经由用户确认的最佳手感；已有设置不会被自动覆盖。重量感需要与弹性配合，单纯增大质量不会使理想单摆的水平周期变慢。

## 实现与优化

- 绳子模式使用原始 227 × 199 RGBA 小猪图片，气球模式使用独立的 270 × 258 透明气球图片，网兜模式使用 207 × 200 的 62 帧透明 APNG，竹子模式使用独立的 1917 × 1367 透明小猪；猪上吊与幽灵猪素材分别从用户参考图提取为 360 × 384 和 374 × 620 的透明 PNG。构建检查所有六种模式素材与包内文件完全一致，原有素材保持不变。
- 每根绳子使用十二段 Verlet/XPBD 弹性绳，以固定 120 Hz 模拟，移动时目标约 60 Hz 更新。计时器调度并非显示同步，不承诺每个显示刷新周期都有新帧。
- 子步插值鼠标锚点，XPBD 仅施加拉力、不施加压缩力，允许松弛；末端质量与弹性顺应度配合形成起步滞后。超大单帧锚点移动平移保留绳身相对姿态，不重置绳端角度；竹子摆角低通平滑，减少快速上下反向造成的视觉闪跳。绘制用平滑二次曲线，避免四段直线的明显折角。
- 拉伸安全上限在弹性 0–100 时从 0% 增至 12%，100–200 时保持 12% 但继续增加顺应度，避免无限拉伸；安全投影会在极端快速拖动时牺牲部分重量滞后。初始化沿当前模式的受力方向展开绳子，稳定后保留受力形状，不突然缩回未受力长度。
- 限制冲击速度；意外长帧间隔跳过未模拟时间并平移保留绳身相对姿态，避免复位跳切。系统睡眠/唤醒由应用显式重置姿态，避免积分发散。
- 所有气球的绳端同步到鼠标且相对受力轴偏差小于 0.2 点、速度足够低后，以 15 Hz 轮询鼠标，停止无意义的物理更新和绘制；检测到移动后恢复 60 Hz，启动延迟最多约 67 ms 加系统调度时间。隐藏或系统睡眠时停表。
- 网兜模式预先加载动画帧，按原时序循环；绳索静止后停止物理积分，保留 25 Hz 动画更新，不冻结角色。隐藏或系统睡眠时同时停止动画与物理，恢复时不追赶隐藏期间的帧。
- 按屏幕创建透明、无阴影、点击穿透、不可成为 key/main 的 NSPanel，设置加入所有 Spaces 和全屏辅助窗口；仅重绘新旧挂件包围区域与屏幕的交集。
- 坐标使用 AppKit 全局点坐标，减去各屏幕原点转换为局部坐标，Retina 由 AppKit 处理。系绳点位于鼠标热点右侧 4 点，仅气球模式上方 6 点，其余模式下方 6 点；没有直接套用 Windows 指针位图比例。竹子模式扩大局部重绘边界，覆盖侧伸的小猪与竹叶。
- 修复 Swift 私有类型访问级别错误、隐藏期间屏幕重建时的计时器状态、失效设置值，并为菜单显示状态添加勾选。

默认重力或净浮力加速度为 1350 点/秒²，阻尼为每 1/60 秒保留 0.985 的速度。绳节点质量为相对单位 1，末端质量映射为 `6 * 10^(重量感/100)`，范围 6–600；顺应度随弹性平方变化，按绳长和段数缩放。气球是带轻微侧向气流的视觉近似，不是气体热力学模拟。幽灵猪不使用绳子物理，按时间平滑趋近鼠标旁的目标点。这些均为本版本适配参数，不直接套用未经验证的 Windows 弹簧刚度、阻尼和质量。原版配置为四段，当前六种模式是针对用户需求的主动调整，不是原引擎还原。原始证据见 [REVERSE_ANALYSIS.md](REVERSE_ANALYSIS.md)。

## 源码组织

运行代码按职责放在 `PigPendant/App`（应用生命周期和协调）、`Core`（数学、模拟与动画时间线）、`Settings`（模式、参数规则和偏好存储）、`Presentation`（素材、场景快照、多屏窗口和绘制）、`Platform`（计时调度）和 `UI`（原生设置及菜单栏）。`main.swift` 仅保留启动及自检分流；既有模式行为保持不变。

`PendantCoordinator` 连接各组件，统一应用设置并通知 UI；`PendantSimulation` 只接收锚点和经过时间，不读取鼠标、系统时钟、窗口或偏好。绘图只消费只读的 `SceneSnapshot`，不再访问协调器或可变物理对象；一帧快照复用于各屏幕。六项参数的范围、默认值、保存键和说明集中在 `ParameterID`，设置窗口以具名参数行组织控件，不再依靠多个平行数组。

物理、设置、模拟及时间线检查位于 `Tests/Core`，GUI、设置和菜单冒烟检查位于 `Tests/Smoke`。[Package.swift](Package.swift) 将 `Core` 和 `Settings` 独立编译为 `PigPendantCore`，用 `PigPendantCoreChecks` 运行具名检查及原有穷举物理回归；核心不依赖 AppKit。检查程序沿用显式断言及失败退出码，不依赖 XCTest、Swift Testing 或第三方库，仅需 Command Line Tools。验证时通过 `-enable-testing` 允许检查目标访问内部类型，不扩大正式代码的公开 API。

应用仍由 `build.sh` 使用相同核心源码进行本机架构编译、组装、签名及 ZIP 打包，不引入第二套应用打包流程。正式 `PigPendant.app` 不编译 `Tests`，GUI 测试另外生成 `PigPendantValidation.app`，只在该构建启用 `TESTING` 和测试访问扩展，不打入发布 ZIP。

`./build.sh --test` 会先将现有偏好导出到 `dist/test-preferences-*.plist`，再运行验证；退出时由外部脚本恢复，测试进程崩溃也会触发恢复。原本没有偏好域时记录 `.absent`。GUI 检查使用唯一的 `local.pigpendant.smoke-tests.<UUID>` 偏好域，核心设置检查也各用独立域；正常或异常退出后由脚本清理 GUI 测试域。强制终止整个脚本或系统断电后，需根据保留的备份手动恢复。直接运行二进制的 GUI 测试时仍须自行备份偏好、传入唯一 `--preferences-suite` 并在退出后执行 `--cleanup-preferences`。

## 自动验证

```bash
./build.sh --test
# 只运行独立核心检查，不启动桌面窗口
swift run --scratch-path dist/swiftpm -c release -Xswiftc -enable-testing PigPendantCoreChecks
# 或在完整验证构建生成后运行原有物理自检
dist/PigPendantValidation.app/Contents/MacOS/PigPendant --self-test
```

验证包的 `--self-test` 不启动 GUI；完整脚本中的 `--smoke-test` 需要已登录的桌面会话，短暂启动验证应用后自动退出。正式应用拒绝这两个测试参数并返回非零退出码，避免误把正式包当作测试包。设置窗口及模式离屏截图保存为应用包相邻的 `settings-smoke.png`、`rope-smoke.png`、`balloons-smoke.png`、`net-smoke.png`、`bamboo-smoke.png`、`hanging-smoke.png`、`ghost-smoke.png`，各模式另有 `<模式>-settings-smoke.png` 设置截图，开发构建对应 `dist/`。

## 竹子小猪效果预览

竹子模式已接入单段动态弯垂；以下独立静态预览脚本保留最初横趴构图，仍可用于提取素材。当前横向、半弯和竖向实绘分别为 `dist/bamboo-moving-smoke.png`、`dist/bamboo-bending-smoke.png` 和 `dist/bamboo-smoke.png`。使用用户提供的竹子小猪原图运行：

```bash
swift tools/preview-bamboo.swift /path/to/reference.png dist
open dist/bamboo-mode-preview.png
```

脚本按该参考图的颜色提取原小猪像素，保留最大连通角色以去掉游离竹节色点，另绘弯曲竹子、竹节和竹叶，输出效果图与透明小猪到忽略目录 `dist/`。不修改原图或用户参数，静态构图不等同于动态手感验收。正式构建直接打包已保存的 [PigPendant/Resources/bamboo-pig.png](PigPendant/Resources/bamboo-pig.png)，不依赖下载目录或预览脚本。

小猪保持整张原图、腿长和身体比例，不做局部拉伸或网格形变；以短前脚和后脚确定整体平移和旋转，让中间长脚自然搭过竹面，形成贴抱姿态，而非强求三个脚尖落在同一条线上。竹叶独立跟随竹梢。三阶段实绘检查横向宽高比超过 1.2、停稳头朝上且角色完整落在截图内部，并检查三处搭接位置同时出现实际猪脚和竹色像素。几何测试覆盖 41 个弯曲阶段、尺寸 16/48/88/256 点、最短可显示长度及 180/1200 点竹长，确保短前脚和后脚贴竹、中间脚的搭接不进入躯干。

连续移动回归在真实控制器中覆盖 30/60/120/144 Hz 快速移动、转向与停留，并确认参考绳实际松弛时，逐帧显示弧长仍保持稳定。另测过渡速度一致、顺时针弯垂、单段起止位置、停稳曲率与两端切线、再次移动抬起、弯垂期间不提前休眠及隐藏/系统睡眠暂停。GUI 静止状态自检期间固定输入锚点，避免用户鼠标活动干扰断言，不移动系统鼠标；正常运行仍直接跟随真实鼠标。浅色背景检查完整轮廓；实际动作观感仍需用户试用确认。
