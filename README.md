# Pig Pet Pendant（猪猪鼠标挂件）

一款跟随鼠标移动的桌面小猪挂件。当前提供 macOS 版本；Windows 版仍在规划中，暂不可用。

![六种模式预览](docs/media/modes.gif)

*预览依次展示六种模式，由应用自动渲染画面合成，非实机录屏。*

## 模式

- **绳子挂件**：默认模式，小猪随鼠标摆动，移动或下坠时作出反应；绳子完全静止后，轻拱身动作会带动小猪和绳子前后荡一下，幅度可在设置中以 0–200% 调节。静止时也会随机眨眼、动耳朵或拱身，动作平滑收尾，不再机械循环整段 GIF。
- **猪猪气球**：显示 1–8 只向上漂浮的猪气球，默认 2 只；各自随机眨眼、轻动耳朵和拱鼻，移动时作出反应。
- **网兜小猪**：使用用户手工处理的新透明图，随机轻动耳朵、拱鼻；蓝色网线保持不动，不再播放旧的 62 帧循环。
- **竹子小猪**：小猪抱着随鼠标动作弯垂的竹子；会随机眨眼、轻动耳朵和拱鼻，动作不改变抱竹接点。
- **猪上吊**：小猪通过绳子悬挂，随机轻抖耳朵或拱鼻；原光环在移动时稍滞后、停止后轻回摆，安静时偶尔歪一下。叉叉眼不眨眼，紫色带子、绳端接点及光环原造型保留。
- **幽灵猪**：不带绳子，平滑跟随鼠标。

## 音乐律动实验

应用启动后会尝试读取系统播放音频，分析低频和中频的能量突变来检测鼓点起音，让菜单栏状态图标在鼓点到来时变大、间隔中回落；桌面挂件尺寸不受影响。这是实时节拍起音估计，不是完整歌曲节拍网格或音乐识别。macOS 14.2 及以上版本首次启动会请求“系统音频录制”权限，仅用于在本机实时分析播放音频中的鼓点以驱动菜单栏图标；不会录制或保存音频，也不请求屏幕录制权限。当前权限或读取状态可在状态栏菜单中查看。

## 使用

点击菜单栏的小猪图标，在菜单中切换模式或打开“设置”。设置会自动保存；关闭设置窗口不会退出挂件。选择“退出猪猪挂件”才会结束应用。

## 构建

需要 macOS 12 或更新版本及 Xcode Command Line Tools。在仓库根目录运行：

```bash
./build.sh
open dist/PigPendant.app
```

构建产物和对应架构的 ZIP 包生成在 `dist/`。应用使用本地临时签名，未经过 Apple 公证；首次在其他 Mac 打开时，系统可能显示安全提示。

可运行构建、物理与 GUI 冒烟检查：

```bash
./build.sh --test
```

GUI 检查需要已登录的桌面会话，会短暂显示测试挂件后自动退出。

绳子小猪的独立透明素材 `PigPendant/Resources/rope-pig.png` 保留原 GIF 全部 75 帧、每帧 40 毫秒；只去除上方长绳及远离角色的游离点，统一悬挂接点，不重绘角色，原静态 `pig.png` 也保留不变。播放时按状态选择短动作，用相近姿态和短暂帧间混合代替首尾硬切。物理静止时仍可随机做小动作；等待期间降低更新频率，隐藏或系统睡眠时暂停。可用 `swift tools/extract-rope-pig.swift source.gif PigPendant/Resources/rope-pig.png` 重新提取原素材。完整帧索引图、接缝分析、动作划分与复现方法见 [角色动画资料](docs/ROPE_ANIMATION.md)。

气球和竹子模式共用上述动作调度，但不套用捆绑猪帧：在各自静态原图的眼睛、耳朵和鼻子邻域进行局部像素变形，生成轻量小动作，不重绘角色、不改写原素材，也不拉伸整只猪。气球的底部系绳区域、竹子小猪的脚部与原有抱竹几何保持不变；不模拟 GIF 中完整的四肢摆动或拱身。多气球分别计时，静止时错开动作；移动和实际下坠触发反应，动作平滑回到原姿态。物理休眠不停止角色动作，隐藏或系统睡眠时暂停并在恢复后继续。绘制副本宽度不超过 512 像素（保留原比例），姿态缓存有内存上限。`./build.sh --test` 另行检查真实闭眼形状、鼻子与脚部像素保护、全部气球的独立状态和暂停恢复，并将浅色背景姿态图及场景序列输出到 `dist/`；这些是自动实绘，不是实机录屏，也不代替主观自然度确认。

局部动作使用 72 段相位采样，播放时按 60 Hz 更新（不是 72 FPS，也不是新增原画帧）。眨眼包含渐进闭合、约 0.2 秒闭眼停留、较慢睁眼和回到待机的过程；耳朵围绕根部摆动，拱鼻也有更清楚的局部位移。GUI 检查另外在 48 点、2 倍像素下验证多级眼睛高度和耳鼻位移，避免只在放大预览中可见；原绳子挂件的原帧播放不受影响。

猪上吊复用局部动作调度，但将眨眼动作映射为耳朵轻抖，不改变叉叉眼。独立耳鼻变形范围按其原图设置，不套用气球的坐标；原素材不改写，身体摆动仍由现有绳子物理负责。光环按透明连通区域从原图分层，用蒙版保留原颜色空间、柔边及闭合轮廓，不重绘、不在原位留下第二个光环。光环通过独立的阻尼视觉跟随产生小幅倾斜和位移：移动时稍滞后，停止或转向后回摆，向下运动时相对上浮；这不是额外绳子受力或真实光环物理。待机时仅在角色安静且光环已停稳的间隙累计约 5–9 秒后轻晃一次，不持续旋转或闪烁。光环未停稳时保持动画更新，不重新唤醒静止绳子；隐藏和睡眠暂停，恢复保留光环姿态。

GUI 检查新图的耳鼻正常尺寸位移、叉叉眼保护、蓝网及透明网眼逐像素不变，以及光环/主体分层的原色和 Alpha 保真；核心检查覆盖光环独立调度、30/60/120/144 Hz 输入、快速转向、收敛、恢复及模式切换。新姿态图为 `dist/net-custom-poses.png` 与 `dist/hanging-custom-poses.png`，模式实绘为 `dist/net-smoke.png` 与 `dist/hanging-smoke.png`（自动实绘，非录屏，不代替主观自然度确认）。

光环按用户反馈逐步放大，当前运动目标倾角上限约 12.5°，待机目标峰值约 9.5°（实际回摆可略超目标），位移随速度和挂件尺寸变化。新图保留该调度与阻尼，重新分离并计算原光环中心。

光环待机动作还会沿小猪局部“头顶平面”的两条斜向轴做随机小游移，每次选择不同起始方向并沿弧线平滑归位，不只靠近/远离身体；这是二维视觉运动，不缩放光环或宣称三维模拟。随机动作仍有安静间隔，移动时保留原滞后/回摆。

用户提供的两张 768×768 单帧透明图已原样保存为 `PigPendant/Resources/net-pig-custom.png` 与 `PigPendant/Resources/hanging-pig-custom.png`，应用使用新图，不再进行自动删白或边缘补色。旧 `net-pig.png`（62 帧）及 `hanging-pig.png` 保留作原始参考，旧网兜帧不参与当前显示。新网兜只裁去左侧 256 像素的近透明空白（边距残点 Alpha 不超过 2%），未裁角色、不拉伸；顶部系绳点随裁剪重新对齐。猪上吊按新图重新设置耳鼻区域、分离光环，不套用旧素材坐标。附图周围剩余的游离残点不做额外全图清理。

新网兜并非恢复原动画：经用户确认，用新静态图生成耳鼻局部动作，网线、网眼不随动作变形；原本闭合的眼睛不强做眨眼。小动作在物理静止时随机播放，移动/下坠触发反应，隐藏或睡眠暂停恢复。旧的自动删白试验已移除，相关经验仅保留在经验记录中。

## 已知限制

- 目前没有 Windows 可执行版本。
- 气球之间没有碰撞检测，也没有屏幕边界限制。
- macOS 没有受支持的接口读取其他应用的全局鼠标指针显隐状态，因此全屏视频隐藏指针时，挂件可能仍显示在画面上。
- 应用不申请辅助功能或屏幕录制权限，不向网络发送请求。
