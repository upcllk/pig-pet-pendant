# Windows 客户端约束

- 与根目录 `AGENTS.md` 的共同产品规则一致；macOS 的 AppKit、`.app`、`build.sh` 和偏好域规则仅适用于原客户端。
- Windows 客户端使用 `windows/` 中的 C# 工程；保留全部模式、原始素材、单实例、点击穿透、不抢焦点和设置持久化。
- 素材只链接 `PigPendant/Resources/` 的源文件，不维护第二份人工编辑素材。
- 构建、自动检查、真实桌面交互验收分别报告；未经测试的多屏、DPI、点击穿透和长期性能不得写成通过。
- 发布使用自包含单文件 EXE，原生运行时可在启动时解包到用户临时目录；构建产物放入忽略的 `dist/`。正式包不编译冒烟代码。
- 跟随 macOS 当前七模式素材和角色动作：绳子 75 帧动作、新网兜静态图、上吊猪独立光环、原幽灵猪分层眨眼与持续下摆、小小幽灵猪独立源图和局部动作、气球和竹子局部动作；保留用户原图与保护区域。两种幽灵的下摆随鼠标二维速度平滑提速。三种带光环模式分别保存光环间距与大小。默认配置在 Windows 用户目录单独复制，升级时只补齐旧配置缺失的新模式；托盘音乐响应只分析 WASAPI 回环实时样本，不保存音频。
- 绳子与幽灵动画切帧在预乘 Alpha 像素中合成后绘制一次；不得用两个半透明图层叠加使不透明主体在视频背景上变淡。验证过渡中主体 Alpha 保持不透明。
