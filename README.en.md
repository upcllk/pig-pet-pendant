# Pig Pet Pendant

A small desktop pig pendant that follows your mouse. The macOS version is available; a Windows version is planned but not yet available.

![Preview of six modes](docs/media/modes.gif)

*The preview shows all six modes in sequence. The images were rendered by the app and combined automatically; they are not a screen recording.*

## Modes

- **Rope Pendant**: The default mode. The pig reacts to movement and falling, with randomly spaced blinks, ear movements, and body gestures at rest. After the rope settles, a body gesture can nudge the pig into a short swing; its amplitude is adjustable from 0–200% in Settings. Actions return smoothly to rest instead of looping the entire GIF.
- **Pig Balloons**: Shows 1–8 pig-shaped balloons floating upward; the default is 2. Each has independently timed blinks, gentle ear movements and nose gestures, with movement reactions.
- **Pig in a Net**: Uses the user's manually cleaned transparent image with random local ear/nose gestures and a fixed blue mesh, replacing the old 62-frame loop.
- **Pig on Bamboo**: The pig hugs a bamboo stalk that bends with mouse movement, with random blinks, ear movements and nose gestures that preserve its grip.
- **Hanging Pig**: Hangs from a rope with randomly timed ear twitches and nose gestures. Its halo lags during movement, rebounds after stopping, and occasionally tilts at rest. Cross eyes do not blink; the band's shape is preserved with the same brown hue as Rope Pendant's binding, alongside the original attachment and halo.
- **Ghost Pig**: Follows the mouse smoothly without a rope.

## Music Reactive Experiment

At launch, the app detects drum onsets from changes in low- and mid-frequency energy in system playback audio. The menu-bar icon grows on detected hits and falls back between them; the desktop pendant is unaffected. This is a real-time onset estimate, not full-song beat-grid or music recognition. On macOS 14.2 or later, first launch requests **System Audio Recording** permission solely to analyze playback locally in real time for drum onsets that drive the menu-bar icon; audio is not recorded or saved, and **Screen Recording** permission is not requested. The current permission or capture status is available in the status-item menu.

## Usage

Click the pig icon in the menu bar to switch modes or open **Settings**. Settings are saved automatically. Closing the Settings window does not quit the app; select **Quit Pig Pet Pendant** to exit.

## Build

Requires macOS 12 or later and Xcode Command Line Tools. From the repository root, run:

```bash
./build.sh
open dist/PigPendant.app
```

The app bundle and a ZIP archive for the current architecture are created in `dist/`. The app uses an ad hoc signature and is not notarized by Apple. When opened on another Mac for the first time, macOS may show a security warning.

To run the build, physics, and GUI smoke checks:

```bash
./build.sh --test
```

## Known Limitations

- A Windows executable is not currently available.
- Balloons do not collide with each other and are not constrained by screen boundaries.
- macOS has no supported API for reading another app's global cursor visibility, so the pendant may remain visible over fullscreen video after the cursor is hidden.
- The app does not request Accessibility or Screen Recording permissions and does not send network requests.
